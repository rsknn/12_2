# Условие задачи

1. Написать программу, которая выводит на экран текущее время.
2. Добавить вывод дополнительной информации: **«до Нового года осталось m месяцев и k дней»**
3. Организовать вывод на экран так, чтобы сообщения размещались точно в центре строки экрана (80 символов), заполнить свободное пространство символами `'*'` и стилизовать вывод в виде прямоугольного окна высотой 10 символов. Для подготовки строк использовать функцию `sprintf()`

# 1. Алгоритм и блок-схема

### Алгоритм

1. **Начало**.
2. **Объявление переменных:** указатель `struct tm *mytime`, переменная `time_t t`, строковые буферы `str1`, `str2` и массив дней в месяцах `days_in_month`.
3. **Получение системного времени:** вызов `t = time(NULL)` и преобразование `mytime = localtime(&t)`.
4. **Расчёт времени до Нового года:**
   * Оставшиеся месяцы: `m = 11 - mytime->tm_mon`.
   * Оставшиеся дни: `k = days_in_month[mytime->tm_mon] - mytime->tm_mday`.
5. **Подготовка строк:** формирование текста в `str1` и `str2` с помощью `sprintf()` и расчёт их длин `len1`, `len2` через `strlen()`.
6. **Цикл вывода окна (`row` от `0` до `9`):**
   * Если `row == 4` или `row == 5` — расчёт боковых отступов `left = (80 - len) / 2`, `right = 80 - len - left`, вывод символов `'*'` слева, текста строки и символов `'*'` справа.
   * В остальных строках — вывод 80 символов `'*'`.
7. **Конец**.

# 2. Реализация программы

```c
#define _CRT_SECURE_NO_DEPRECATE
#include <stdio.h>
#include <string.h>
#include <time.h>
#include <locale.h>
#define WIDTH 80
#define HEIGHT 10

int main() {
    setlocale(LC_CTYPE, "RUS");
    struct tm* mytime;
    time_t t;
    char str1[100];
    char str2[100];
    int days_in_month[12] = { 31, 28, 31, 30, 31, 30, 31, 31, 30, 31, 30, 31 };
    t = time(NULL);
    mytime = localtime(&t);
    int m = 11 - mytime->tm_mon;
    int k = days_in_month[mytime->tm_mon] - mytime->tm_mday;
    sprintf(str1, " Московское время %02d:%02d:%02d ", mytime->tm_hour, mytime->tm_min, mytime->tm_sec);
    sprintf(str2, " до Нового года осталось %d месяцев и %d дней ", m, k);
    int len1 = (int)strlen(str1);
    int len2 = (int)strlen(str2);
    for (int row = 0; row < HEIGHT; row++) {
        if (row == 4) {
            int left = (WIDTH - len1) / 2;
            int right = WIDTH - len1 - left;
            for (int i = 0; i < left; i++) putchar('*');
            printf("%s", str1);
            for (int i = 0; i < right; i++) putchar('*');
            putchar('\n');
        }
        else if (row == 5) {
            int left = (WIDTH - len2) / 2;
            int right = WIDTH - len2 - left;
            for (int i = 0; i < left; i++) putchar('*');
            printf("%s", str2);
            for (int i = 0; i < right; i++) putchar('*');
            putchar('\n');
        }
        else {
            for (int i = 0; i < WIDTH; i++) putchar('*');
            putchar('\n');
        }
    }
    return 0;
}
```
